## About NeonSMP

Welcome to **NeonSMP**, a survival multiplayer server for Minecraft Java and Bedrock players. NeonSMP runs on **Paper** and uses Geyser and Floodgate to support cross-platform play.

This README is the central place for connection details, joining help, server plugins, community guidelines, and screenshots. Server settings and community information can change, so check the [Discord](https://discord.gg/gpADZM) for the latest announcements.

## Connect to the server

### Java Edition

1. Open **Minecraft: Java Edition** and choose **Multiplayer**.
2. Select **Add Server** (or **Direct Connection**).
3. Enter `neonmc.aternos.me` as the server address.
4. Save the entry if desired, then select it to connect.

### Bedrock Edition

1. Open **Minecraft: Bedrock Edition** and go to **Play → Servers**.
2. Choose **Add Server** or **Add External Server**.
3. Enter **NeonSMP** as the server name (this label is just for your server list).
4. Enter `neonmc.aternos.me` as the server address and `19132` as the port.
5. Save the entry and connect.

> **Crossplay:** Java players connect using the Java address. Bedrock players use the same address with the Bedrock port shown above. If you have trouble joining, check the Discord for current server availability and announcements.

## Server features

- **Survival SMP** — a shared survival multiplayer experience.
- **Java & Bedrock crossplay** — play across supported Minecraft editions with Geyser and Floodgate.
- **Paper server software** — the server runs Paper.
- **Community Discord** — connect with the NeonSMP community and check for updates.
- **Teams and permissions** — supported by the installed BetterTeams and LuckPerms plugins.
- **Tab list and leaderboards** — supported by TAB, PlaceholderAPI, DecentHolograms, and AJLeaderboards.
