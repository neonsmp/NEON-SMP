Connect to NeonSMP

Java and Bedrock players use the same address. Bedrock also needs the port.

Java Edition

Addressneonmc.aternos.me
  1. Open Minecraft: Java Edition and choose Multiplayer.
  2. Select Add Server (or Direct Connection).
  3. Enter the address above.
  4. Save the entry if you like, then select it to connect.

Bedrock Edition

Addressneonmc.aternos.me
Port19132
  1. Open Minecraft: Bedrock Edition and go to Play → Servers.
  2. Choose Add Server or Add External Server.
  3. Enter NeonSMP as the server name.
  4. Enter the address and port above, then save and connect.

Server rules

Discord announcements or in-game staff guidance may add details.

  1. Be respectful. Treat players and staff courteously. Harassment, hate speech and targeted abuse are not welcome.
  2. Play fairly. Do not use cheats, hacked clients or exploits to gain an unfair advantage.
  3. No griefing or stealing. Respect other players' builds, belongings and claimed areas.
  4. Keep chat appropriate. Avoid spam, disruptive behavior and inappropriate content.
  5. Do not advertise without permission. This includes unsolicited links or promotion in chat.
  6. Follow staff directions. If you disagree with a moderation decision, raise it calmly through the appropriate community channel.
